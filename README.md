# Kinepolis add-on voor Home Assistant

Scanners voor Kinepolis-films (ook films die nog niet in verkoop zijn): zodra er een
voorstelling is, stelt de add-on de beste plaatsen voor via Telegram en de app, en zet
ze na je *Ja* in je mandje. Betalen doe je zelf.

**Toevoegen aan Home Assistant:** Instellingen → Add-ons → Add-on Store → ⋮ → Repositories →
`https://github.com/Biermienjo/kinepolis-addon`

Uitleg en instellingen: [kinepolis_bot/README.md](kinepolis_bot/README.md)
